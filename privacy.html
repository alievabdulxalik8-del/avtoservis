Политика конфиденциальности

Последнее обновление: сентябрь 2026

1. Какие данные собираются

При записи на сервис через сайт мы собираем минимально необходимые данные: имя, номер телефона, марку и государственный номер автомобиля, а также описание неисправности. При оформлении заказ-наряда мастером также фиксируются сведения о выполненных работах и стоимости.

2. Для чего используются данные

  • Для записи в очередь и уведомления о статусе ремонта;
  • Для оформления заказ-наряда и истории обращений;
  • Для связи с клиентом по указанному телефону (звонок, WhatsApp).

Данные не используются для рекламных рассылок и не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

3. Где хранятся данные

Данные хранятся в защищённой базе данных с ограниченным доступом. Соединение между сайтом и сервером шифруется (HTTPS). Доступ к данным имеет только владелец сервиса и уполномоченные мастера.

4. Хранение и удаление

Данные хранятся до тех пор, пока это необходимо для целей обслуживания, либо до запроса клиента на удаление. Чтобы удалить свои данные из базы, свяжитесь с нами по контактному телефону, указанному на сайте.

5. Согласие

Отправляя заявку на запись через сайт, вы соглашаетесь с обработкой указанных данных в целях, описанных выше, в соответствии с Федеральным законом №152-ФЗ «О персональных данных».

6. Контакты

По всем вопросам, связанным с обработкой персональных данных, обращайтесь по телефону, указанному на главной странице сайта.
